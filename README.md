# Steam 小黑屋

一个简单的 Windows 自律工具，用来暂时封禁 Steam，或者限制一次游玩的时长。

## 使用

下载仓库中的 [SteamStudyLock.exe](SteamStudyLock.exe)，双击运行，并允许 Windows 的管理员权限提示。无需安装 Python 或开发工具。

### 封禁 Steam

设置分钟数，点击“开始封禁”立即生效。正在运行的 Steam 会关闭，封禁期间不能再次启动。图标保留，程序没有提前解锁按钮。

关闭窗口、重启电脑后封禁仍有效，到期自动恢复。界面只显示开始时间和封禁时长，不显示倒计时或结束时间。

### 游玩计时

设置分钟数，点击“开始游玩计时”，再自行打开 Steam。计时从点击按钮时开始，不是固定时间段，也不统计游戏的实际前台时间。

1. 游玩时间到，弹窗提醒保存进度。
2. 提醒出现后留出 10 分钟宽限。
3. 宽限结束后，向识别到的 Steam 游戏及其子进程发送正常退出请求；确认游戏进程全部结束后，再请求 Steam 正常退出。即使提前退出 Steam，仍会处理继续运行的游戏。

点“知道了”、关闭提醒或主窗口都不会取消计时。本次开始后不能修改时长。游玩计时和封禁不能同时进行；游玩计时结束不会自动转入封禁，也不会阻止之后重新打开 Steam。

## 运行方式

- 面向 Windows 10 / 11，使用 C#、Windows Forms 和系统自带的 .NET Framework。
- 首次启用时将程序复制到 `%ProgramFiles%\SteamStudyLock`。
- 封禁使用 Windows 的程序启动拦截设置和 `SteamStudyLock_Expiry` 恢复任务。
- 游玩计时使用 `SteamStudyLock_PlayTimer` 任务，在当前 Windows 用户的桌面运行后台计时器。
- 记录保存在 `HKLM\SOFTWARE\SteamStudyLock`。封禁只保存开始时间和分钟数；游玩计时额外保存首次提醒时间，计时结束后删除游玩记录。
- 休眠或关机期间错过首次提醒时，恢复后提醒并给完整 10 分钟。已提醒的宽限不会因重启重新开始。后台恢复检查可能有约 1 分钟延迟。

## 编译与测试

在 Windows PowerShell 中运行：

```powershell
.\build.ps1
.\test.ps1
```

构建使用系统 .NET Framework C# 编译器。测试覆盖封禁到期、游玩到时、完整宽限、Steam 游戏库识别、路径边界、启动器退出后的游戏子进程、进程编号复用，以及拒绝退出时保留进程、正常退出时完成模拟存档和无关进程保留。测试只创建并关闭专用测试进程，不操作真实 Steam 或游戏。

已完成编译、时间边界测试及主界面布局检查。实际游戏与 Steam 正常退出的兼容性仍需在目标电脑验证；已通过专用进程的正常退出和模拟存档测试。

## 使用边界

- 请利用宽限时间手动保存进度。程序无法通用确认游戏是否已经存档，因此不会强杀游戏：游戏弹出保存确认、拒绝退出或没有可关闭的主窗口时，保留 Steam 并提示手动处理。进程退出只表示游戏已结束，不能证明游戏或云同步实际保存成功。
- 游玩计时识别标准 Steam 游戏库中已安装游戏的可执行程序，并跟踪其非 Windows 系统子进程；关闭范围限当前 Windows 会话。提前退出 Steam 不会取消游戏关闭。非 Steam 快捷方式、无法读取的受保护进程、短暂启动器已退出且未被观察到的库外游戏进程可能漏识别。
- 独占全屏游戏可能遮住提醒，建议使用无边框窗口模式。
- 这是自律工具，拥有管理员权限的人仍可通过修改系统设置、程序文件或系统时钟绕过。

详细使用说明见 [使用说明.txt](使用说明.txt)。

## 游戏关闭修复

旧版只结束 `steam.exe`，会留下独立运行的游戏。本版在整个计时期间识别游戏库进程并跟踪子进程，宽限结束后先请求游戏正常退出，确认游戏进程结束后再通过 Steam 的正常退出命令关闭客户端。游戏仍运行时保留 Steam；已经发出的正常退出请求不会反复打断保存对话框。根据路径和启动时间核对进程身份，避免进程编号复用导致误关。此修复作用于游玩计时的到期处理，立即封禁按钮仍只处理客户端启动限制。
