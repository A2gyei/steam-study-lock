# Steam 小黑屋

一个简单的 Windows 自律工具，用来暂时封禁 Steam，或者限制一次游玩的时长。

## 使用

下载仓库中的 [SteamStudyLock.exe](SteamStudyLock.exe)，双击运行，并允许 Windows 的管理员权限提示。无需安装 Python 或开发工具。

### 封禁 Steam

设置分钟数，点击“开始封禁”立即生效。正在运行的 Steam 会关闭，封禁期间不能再次启动。图标保留，程序没有提前解锁按钮。

关闭窗口、重启电脑后封禁仍有效，到期自动恢复。界面只显示开始时间和封禁时长，不显示倒计时或结束时间。

### 游玩计时

设置分钟数，点击“开始游玩计时”，再自行打开 Steam。计时从点击按钮时开始，不是固定时间段，也不统计游戏的实际前台时间。

1. 游玩时间到，弹窗提醒保存进度。
2. 提醒出现后留出 10 分钟宽限。
3. 宽限结束后，如果 Steam 仍在运行，就自动关闭；已关闭则结束本次计时。

点“知道了”、关闭提醒或主窗口都不会取消计时。本次开始后不能修改时长。游玩计时和封禁不能同时进行；游玩计时结束不会自动转入封禁，也不会阻止之后重新打开 Steam。

## 运行方式

- 面向 Windows 10 / 11，使用 C#、Windows Forms 和系统自带的 .NET Framework。
- 首次启用时将程序复制到 `%ProgramFiles%\SteamStudyLock`。
- 封禁使用 Windows 的程序启动拦截设置和 `SteamStudyLock_Expiry` 恢复任务。
- 游玩计时使用 `SteamStudyLock_PlayTimer` 任务，在当前 Windows 用户的桌面运行后台计时器。
- 记录保存在 `HKLM\SOFTWARE\SteamStudyLock`。封禁只保存开始时间和分钟数；游玩计时额外保存首次提醒时间，计时结束后删除游玩记录。
- 休眠或关机期间错过首次提醒时，恢复后提醒并给完整 10 分钟。已提醒的宽限不会因重启重新开始。后台恢复检查可能有约 1 分钟延迟。

## 编译与测试

在 Windows PowerShell 中运行：

```powershell
.\build.ps1
.\test.ps1
```

构建使用系统 .NET Framework C# 编译器。测试覆盖封禁到期、游玩到时、延迟提醒后的完整宽限和强制关闭时间边界，不启用真实封禁，不关闭真实 Steam。

已完成编译、时间边界测试及主界面布局检查。计划任务注册、实际提醒和 Steam 关闭行为尚需在目标电脑上实测。

## 使用边界

- 请利用宽限时间保存进度，强制关闭可能影响未保存的内容。
- 程序只处理标准 `steam.exe` 客户端，不保证关闭已经独立运行的游戏。
- 独占全屏游戏可能遮住提醒，建议使用无边框窗口模式。
- 这是自律工具，拥有管理员权限的人仍可通过修改系统设置、程序文件或系统时钟绕过。
